# Mis Finanzas

App para controlar gastos e ingresos desde el iPhone: gastos e ingresos diarios, salario y gastos fijos mensuales, gráficas para ver si estás en déficit y extracto en PDF.

La app está en la carpeta `docs` y se publica con GitHub Pages:
https://danielestebanparra-alt.github.io/Control-gastos-app/

Para instalarla en el iPhone: abre el enlace en Safari → Compartir → Agregar a pantalla de inicio.

Los datos se guardan solo en el celular, no en GitHub.
